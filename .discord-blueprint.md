# Discord Channel Integration - Blueprint

## Overview

This blueprint configures CREST to receive customer complaints via Discord Direct Messages and send automated replies back to customers.

## Architecture

```
Discord User → DM @bot → Discord API → CREST Webhook
                                           ↓
                                      Parse + Verify
                                           ↓
                                    Create Complaint
                                           ↓
                                      Add to Queue
                                           ↓
                              Employee Processes & Approves
                                           ↓
                                    send_discord_dm()
                                           ↓
                              Reply sent back to customer
```

## Components Added

### Backend API (`backend/api/discord.py`)
- **Endpoint**: `POST /api/integrations/discord/webhook`
- **Features**:
  - Ed25519 signature verification using `DISCORD_PUBLIC_KEY`
  - Handles Discord interactions (PING, MESSAGE_CREATE, etc.)
  - Filters out bot messages
  - Converts DMs to CREST complaints
  - Type 1 (PING) → Type 1 (PONG) for Discord verification

### Discord Sender (`integrations/discord/sender.py`)
- **Function**: `send_discord_dm(user_id, reply_text)`
- **Features**:
  - Creates DM channel if not exists
  - Sends message via Discord Bot API
  - Supports simulated mode (mock_discord_token)
  - Returns message_id for audit trail

### Complaint Service Integration (`backend/services/complaint_service.py`)
- **Updated**: `approve_draft()` function
- **Logic**: Routes Discord replies to `send_discord_dm()`
- **Channel Detection**: Checks `complaint.channel.name == "discord"`

### Optional Gateway Listener (`integrations/discord/listener.py`)
- Uses `discord.py` library
- Connects to Discord gateway
- Forwards DMs to CREST webhook
- Can run as separate microservice

## Setup Steps

### 1. Create Discord Bot

Visit: https://discord.com/developers/applications

```yaml
Steps:
  - Click: "New Application"
  - Name: "CREST Support"
  - Tab: "Bot"
  - Action: "Add Bot"
  - Copy: "TOKEN" → DISCORD_BOT_TOKEN
  - Copy: "PUBLIC KEY" from General Information → DISCORD_PUBLIC_KEY
```

### 2. Configure Permissions

```yaml
OAuth2:
  Scopes:
    - bot
  Permissions:
    - send_messages
    - read_messages
    - read_message_history
```

### 3. Invite Bot to Discord Server

1. Generate invite URL from OAuth2 URL Generator
2. Open URL and select server to authorize
3. Bot is now member of your server

### 4. Set Environment Variables (Render)

```yaml
Render Dashboard:
  Service: crest-api
  Tab: Environment
  Variables:
    DISCORD_BOT_TOKEN: "<token-from-step-1>"
    DISCORD_PUBLIC_KEY: "<public-key-from-step-1>"
  Action: Save → Auto-redeploy
```

### 5. Configure Webhook Endpoint

**Option A: HTTP Interactions (Recommended)**

Discord Developer Portal:
```yaml
Interactions Endpoint URL: "https://crest-api-z8zf.onrender.com/api/integrations/discord/webhook"
```

Discord auto-verifies by sending PING request.

**Option B: Gateway Bot (Production)**

Deploy `integrations/discord/listener.py` as separate service with same env vars.

### 6. Create Discord Channel in Database

```bash
python scripts/setup_discord_channel.py
```

Or via SQL:
```sql
INSERT INTO channels (name, is_active) VALUES ('discord', true);
```

### 7. Test Integration

```bash
python scripts/test_discord_integration.py
```

Runs 5 tests:
- ✅ Endpoint accessibility
- ✅ Webhook data format
- ✅ Bot message filtering
- ✅ PING interaction
- ✅ Simulated DM ingestion

## API Contract

### Incoming Discord Interaction

```json
{
  "type": 0,
  "message": {
    "id": "message_id",
    "channel_id": "dm_channel_id",
    "author": {
      "id": "user_id",
      "username": "customer_name",
      "bot": false
    },
    "content": "Customer complaint text"
  }
}
```

### Complaint Created With

```python
{
    "channel": "discord",
    "customer_id": "<discord_user_id>",
    "customer_name": "<discord_username>",
    "body": "<message_content>",
    "subject": "Discord DM from <username>",
    "external_ref": "<message_id>"
}
```

### Reply Sending

```python
send_discord_dm(
    user_id="123456789",
    reply_text="Your issue has been resolved...",
    external_ref="msg_id_123"
)
```

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Signature verification failed | Check DISCORD_PUBLIC_KEY matches Developer Portal |
| Bot not receiving DMs | Verify permissions and webhook URL configured |
| Replies not sending | Verify DISCORD_BOT_TOKEN is valid and user has DMs enabled |
| 404 on webhook endpoint | Ensure discord_router is registered in main.py |
